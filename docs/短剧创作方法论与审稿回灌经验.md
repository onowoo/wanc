# wanc 审稿→回灌→改稿 方法论文档

> 本文件是《神级医仙》男频神医逆袭短剧**七轮"外部审稿→回灌工程→示范改稿→复检重导交付"打磨**的经验沉淀。
> 目的：让任何一部新剧本复用这套方法论，让 wanc 工程"一次审稿、永久增益"。
> 硬性规则见 `backend/app/services/validator.py`；写作规范见 `backend/app/templates/submit_template.yaml`；本文件解释**为什么**、**怎么用**。

---

## 一、闭环工作流（固定循环）

外部审稿（人或 AI 评测）→ 回灌工程（validator 规则 + submit_template 规范）→ 示范改稿 → 复检重导交付 → 进入下一轮。每轮都让工程质量只升不降：

```
审稿 →【回灌】validator 加可检测规则 / 模板加写作规范
     →【改稿】挑评测点名的集做示范性改写（或全量优化）
     →【复检】QC 必须回到 100 零告警
     →【交付】重导出投稿包 + git 提交推送 + 重启后端加载新规则
```

核心原则：
- **审稿的每条痛点，要么转化为 validator 可检测规则，要么转化为模板规范**，不允许只改正文而不回灌——否则换下一部剧本时同样的坑还会踩。
- **示范改稿要精、要可复制**，不只修被点名的那一集，而是提炼成可复用的写法。
- **回灌规则的词表要收敛防误报**（见 §六复盘教训），宽词会误伤主角正常行为。

## 二、人物一致性方法论（杜绝 OOC / 性格跳变）

人物卡三要素 + 全程校验：

| 要素 | 作用 | 落地 |
|---|---|---|
| 核心欲望 | 角色行动的动机 | 主角"洗爷爷冤屈、守医道"；反派王强"霸占医方医馆" |
| 弱点 | 主角有挣扎、非完美圣人 | 秦昭"对信任的人心软、念旧" |
| 禁止行为 | 红线，防止人设崩坏 | 王强"贪财爱面子、不当众失态"；秦昭"恩怨分明、不纵容害人者" |

执行要点（本剧本七轮零 OOC 的保证）：
- **弱点必须"落地"成情节**，不能只写进人物卡而剧情不体现。例：秦昭"念旧心软"落地为 25 集对顺子——**念旧情但坚持送官**、向县令陈情从轻判，兼顾法理与人情，而不是因旧情放过重罪。
- **禁止行为要能自动核对**。validator 抽查"王强不当众失态：未见"，防反派在剧情里失控。
- **动机前置**：反派的坏要有内在根源，不能等到结局才揭秘。王强"继承父辈抢来的医术"的悲剧底色在第 7 集独白就埋下，而非 29 集空降。
- **新角色要交代来历**：任何空降的工具人（报信人、证人）需一句话补全"为何愿为主角冒险"。

## 三、AI 味特征清单（识别 + 规避）

六轮审稿反复点名的高频 AI 痕迹，逐条给规避法：

| AI 味特征 | 表现 | 规避手法 |
|---|---|---|
| 格式高度模板化 | 每集固定【场景｜时间】【动作】【本集钩子】，场景只剩功能性地点 | 补环境感官细节：药香/尘土/火场烟尘/光影/旧木朽味 |
| 桥段打卡式堆砌 | 神医短剧要素清单依次排布（回乡受辱→救人→陷害→贵人→鸿门宴→绑架→马甲→公堂） | 删/并同质化桥段；连续冲突间插温情行医单元 |
| 对话工具化 | 村民集体感叹/起哄，反派标准"阴笑"，主角永远冷静无情绪 | 村民加个体不同立场（胆小/摇摆）；对白加碎句、留白；主角保留压抑的愤怒与心痛 |
| 动作词高频复用 | 皮笑肉不笑/脸色青白/攥紧拳头/拂袖而去 反复出现 | 换差异化微神态：捏杯、指尖掐掌心、捋须掩饰、低头饮茶避开目光 |
| 事件重结果轻过程 | 查证、走访一笔带过，直接拿到结果 | 主角主动暗访、寻访证人，证据靠推理+物证，不靠他人送线索 |
| 巧合/偷听/天降贵人 | 主角刚好撞破密谋、贵人卡点救场 | 偷听改线人回报；贵人立场灰度+主角提前布局（赴宴前托人望风） |
| 钩子模板化 | 物证/黑影/密信/印章 循环 | 钩子做差异化：情感钩子、证据升级、预告式钩子 |
| 主题靠台词 | "医道一途只求济世"大道理，缺事件支撑 | 主题事件支撑：独立行医救人完整段落（§五） |

## 四、逻辑闭环手法（短剧逻辑自洽）

审稿从"逻辑 6.2"提到"逻辑 7.6"的关键，全在这里：

- **证据链设计**：翻案不能靠主角口才。物证+人证层层对应——药方残页印章、旧案卷宗、毒药材、被篡改卷宗、万春堂密信、纵火密信、老孙黑账、人证顺子。每一项指控都要有实体证据。
- **物证来源合理**：关键物证不能"恰好掉落"。官印不会随身给纵火打手携带（这是跨集 bug 重灾区）；改成**亲笔密信**被火燎后遗落才合理。
- **官府流程**：官差出动必须有触发链——谁举报、县令是否批复、师爷不能独立调动官差。钱师爷私下作恶但调不动官差，县令本人公正，权责清晰。
- **伏笔回收**：反派"找人封口"埋线后，证人必须在后续集出场作证或揭发；"黑账藏在地窖"口头线索必须**实体化**（取回账本、公堂呈堂），禁止半悬空。
- **跨集物证一致性**：某集更换/删除物证，所有后续引用该物证的集必须同步改（第 27 集官印改密信，第 28 集仍引用官印 → 跨集不一致 bug）。
- **人设法理平衡**：主角念旧但不能徇私废法——顺子投毒是重罪，主角送官+陈情从轻，人情与王法兼顾，既落地弱点又不崩人设。

## 五、反 AI 味写作手法（可直接复用）

已在本剧本示范落地的写法，新剧本直接套：

1. **偷听改线人**：主角不亲自趴在窗外/站门外撞破密谋，改成安排的眼线/线人听到后回报。规避"反派密谋恰好被主角听到"的强行巧合。
2. **贵人灰度 + 主角布局**：贵人不无条件信任主角，早期因利益关系摇摆；关键危机由主角**提前布局**化解（赴鸿门宴前托村人望风、证据备份分存），而不是贵人卡点救场。
3. **主动调查**：主角主动暗访当年证人、走访民间搜证，不全部被动接反派招数。
4. **口语化 + 动作优先于说教**：把"医道一途只求济世"改成"我行医，只求救人，不在乎什么世家名头"；口号式独白改成边做边低声说。
5. **差异化微神态**：替代"脸色铁青/冷笑"，用捏茶杯、指尖掐掌心、假装捋须掩饰慌张、低头喝茶避开目光。
6. **环境感官细节**：药铺的药香与霉味、义诊日的尘土、火场的呛人烟火、老医馆的木朽味。
7. **群像差异化**：不只集体欢呼/愤怒/感恩，加 1–2 个胆小怕事、怕反派报复不敢公开支持主角的个体村民，后期才慢慢改观。
8. **反派动机前置 + 悲剧底色**：反派之坏源于被父辈扭曲的价值观，第 7 集就埋，不等到结局揭秘。
9. **主题事件支撑**：核心立意（悬壶济世）由独立行医救人事件支撑——如久病村民被隔日复诊、半月换药、一月下地的完整段落，脱离冲突线，张弛有度。

## 六、七轮打磨复盘表（痛点→回灌→改法→效果）

评分轨迹：剧情 6.8→7.4→7.8；逻辑 6.2→7.2→7.6；AI 味"较重"→"中等"→"中等偏低"；精彩 7.0→7.3→7.6。

| 轮 | 审稿核心痛点 | 回灌工程 | 示范改稿 | 效果 |
|---|---|---|---|---|
| 1 | 目标40vs正文30、印鉴曝光过早、时间线矛盾、角色冗余、场景标注 | 基础规则（missing_hook/word_count/target_mismatch/scene_inout/line_density） | 印鉴挪第20集、target改30、师叔并入赵叔、【内】改【外】、王强补动机 | 硬伤清零 |
| 2 | AI味（金句/情绪扁平/机械降贵人/偷听/工具人/钩子模板） | ai_maxim/ai_written/ai_repeat_word/ai_deus_ex_machina/ai_eavesdrop/ai_hook_single | 改4/5/7/10/29集：去"恰在此刻"、偷听改情感钩子、王强加自卑底色、口语化 | QC 26→50 |
| 3 | 弱点悬空、偷听巧合、贵人权重、配角单薄、续集钩子空降 | weakness_grounded/cliff_hook_unforeshadowed | 改13/19/20/21/25集：鸿门宴改主角布局托阿贵、亲趴窗改眼线、撞破密谋改福嫂、续集铺垫、顺子心软落地 | 弱点真正落地 |
| 4 | 剧情6.8/逻辑6.2/AI味较重/精彩7.0 | ai_repeat_plot/ai_info_giveaway/gov_action_untriggered | 全量30集偏高优化 + 改6集：官差补举报来源、杀手只吐碎片线索、诈死改篡改卷宗、顺子送官、27官印改密信、30删续集钩子 | 大逻辑硬伤修复 |
| 5 | 剧情7.4/逻辑7.2/AI味中等/精彩7.3 | abandoned_foreshadow（封口→老孙出场） | 改4集：7王强悲剧底色前置、13补阿贵来历、20官差触发、24回收老孙伏笔 | QC 96→100 |
| 6 | 剧情7.8/逻辑7.6/AI味中等偏低/精彩7.6 | abandoned_foreshadow 扩展（实体线索未物证化） | 改2集：24取回黑账实体、28删遗留官印改密信+黑账呈堂 | QC 98→100 |
| 7 | 可投递，3小点（温情集/群像/感官） | 模板37条（主题事件支撑） | 改15集：久病瘦汉调理治愈+胆小村民丁+药香尘土 | QC 100 |

**复盘教训（回灌词表收敛防误报，血泪踩坑）**：
- ai_maxim 初版宽匹配误报多 → 收敛为排比正则 + fallback 词表。
- weakness_grounded 只检主角、词表收敛，避免王强"迟疑"误触发。
- ai_repeat_plot 先含"设局/构陷"误杀主角主动布局 → 收敛为诬告/诬陷/诈死/陷害/买凶。
- gov_action_untriggered 先含"官府"误报第24集 → 剔除。
- abandoned_foreshadow 回收词先含"呈上/账册"被第26集"呈上铁证"误判 → 收敛到证人实体（老孙）+ 物证名（黑账）。

## 七、validator 规则速查（backend/app/services/validator.py，以文件为准）

- 基础：missing_hook / word_count(300–500) / sensitive / ooc / scene_inout / line_density(≥0.35) / novel_narration / slow_open / redundant_role / target_mismatch
- AI味：ai_maxim（排比+金句词表）/ ai_written（"既然/然而/倘若/岂/莫非"等）/ ai_repeat_word（脸色铁青/攥紧拳头等，阈值5）/ ai_deus_ex_machina（恰好/刚好/正巧等，阈值3）/ ai_eavesdrop（趴窗/墙根/站在门外等，阈值4）/ ai_hook_single（>60%单集同型钩子）
- 弱点落地：weakness_grounded（主角词表：心软/念旧/旧情/放他一马/饶他一回/狠不下心）
- 续集钩子铺垫：cliff_hook_unforeshadowed（京城/太医院/神秘/主子等，铺垫<2告警）
- 桥段同质化：ai_repeat_plot（诬告/诬陷/诈死/陷害/买凶，阈值4）
- 信息白送：ai_info_giveaway（全盘招供/和盘托出/一五一十/都说了等）
- 官差触发缺失：gov_action_untriggered（官差/衙役出动无举报/县令批复触发）
- 伏笔未回收/线索未实体化：abandoned_foreshadow（setup：封口/闭了嘴/藏在地窖/留了底；recover：老孙/老账房/黑账）

## 九、新剧本 / 新审稿回灌操作路径

拿到一份新审稿或启动新剧本时，按此执行（详见 wanc 既有 scripts/revamp*.py 与 qc_full.py）：

1. **读审稿，逐条分类**：逻辑硬伤 / AI 味 / 人物一致性 / 主题表达，标出"可检测"与"可规范"。
2. **回灌 validator**：可检测的痛点→加规则；先小词表试跑，防误报（§六教训）。
3. **回灌 submit_template**：写作型痛点→加规范条目，编号递增。
4. **示范改稿**：挑被点名集做示范改写（或全量优化），手法参照 §五；保 300–500 字、台词密度≥35%。
5. **复检**：`python scripts/qc_full.py` 必须回到 100 零告警。
6. **重导出 + 提交推送 + 重启后端**：`scripts/export_pack.py` 出最新投稿包；`git add -A && git commit && git push`；停 8000 端口重启 uvicorn 加载新规则。
7. **更新本方法论文档**：把本轮痛点/回灌/改法追加进 §六复盘表，让经验持续累积。
